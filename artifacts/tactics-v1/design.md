# 机关战术

玩家循环：观察蓝色湿滑内线/干燥外线 → 在传送带入口选择顺向或中间普通路 → 预判炸弹引信换线，或用星星穿过混战区。首版城堡 .17–.24 湿滑区、.30–.39 双带，不改桥、垂直层和既有跳台。主路保留连续安全选择。

保留现有 60Hz 世界坐标驾驶与扫掠圆护栏。湿地降低抓地/参考极速且离开渐变恢复；传送带提供独立道路切向速度，停驶/倒车仍受带动，空中不受。AI采用同一查询、速度系数、带速和提前车道决策，并对引信炸弹避让。

炸弹前抛/后放，2.2秒引信，12米可见范围，范围伤害按世界距离/高度/遮挡一次结算；前0.4秒不接触引爆，投掷者前0.8秒接触保护。星星5秒，独立无敌状态、速度奖励和碰车攻击，仍需玩家转向且保留护栏碰撞。强道具按名次、领先差距和独立冷却分配。八类图标/车顶提示/声音均接入。

状态边界：暂停冻结机关、引信和星星；重赛/退出/切站清理；保留同赛道配置试驾并增加城堡机关试驾入口（不记成绩）。云GP6/TT5，本机规则命名空间升级 tactics1；旧数据保留。无新增外部服务或依赖。

验收：纯规则和完整后端回归；键盘真实驾驶带速/湿滑/炸弹/星星；触屏/手柄同道具入口；暂停、重开和杯赛切站；城堡真实三圈无异常救援；桌面/390手机/844横屏截图，生产构建检查。
