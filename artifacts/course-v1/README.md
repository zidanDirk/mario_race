# 双捷径与赛道机关验证

已实现北侧花园捷径（宽12m，缩短30.60m）和南侧工坊捷径（宽9m，缩短34.96m）。安全主路保持18m宽。花园喷气口绿灯安全3秒、黄灯预警2秒、红灯喷发3秒，行车方向右侧可绕行；工坊路障横向移动，可观察空位后通过。每条捷径的出口加速每圈最多触发一次。

地图增加分支和玩家真实位置；入口标牌、路面箭头、机关提示、指南和结算统计已接入。机关用比赛时间驱动，暂停冻结，重开清零；撞击减速并损失最多3枚金币，不传送车辆。新标牌/路边桩使用碰撞代理，入口支架已移开主路。

## 验证结果

- 原有33项驾驶、碰撞、道具、连续性单元检查通过。
- 新增10组路线/机关确定性检查通过：连续投影、有序三圈、逆行/跳关拒绝、实际物理转向、预警时段、相对运动扫掠和重置。
- 新增10组浏览器检查通过，报告 browser.json。实际键盘穿行花园和工坊路线，均无机关命中、无救援、出口加速触发一次、回主路无漏圈。工坊驾驶过程有2个采样点短暂越过路面边缘，控制仍正常。
- 最终静态通行空间检查：主路三条常用车道1000点采样最小间隙3.20m；两条捷径中心最小间隙7.45m / 5.96m，均超过车辆半径1.6m。此检查排除刻意设置的动态路障。
- 原有17组真实浏览器驾驶回归通过，包括完整三圈49.367秒、第一名、漂移/道具/后视/重开/触屏，无浏览器错误。报告 regression/playtest.json。随后只调整标牌位置并添加支架碰撞，最终专项浏览器与静态通行检查已重跑通过。
- 后端12组检查通过，包括新赛道规则版本2隔离历史成绩、拒绝旧客户端/旧比赛凭证，保留历史记录。前端开赛提交版本2，本机最佳也使用独立键。
- 生产构建通过，JS约628KB，现有大包提示仍存在。

额外运行旧 tests/interaction-browser.mjs 的请求被自动审批因工具额度限制拒绝，未执行该补充回归，不计入通过项。真实手机硬件、手柄硬件及线上部署未在本轮验证。
