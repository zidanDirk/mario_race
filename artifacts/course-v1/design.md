# 赛道机关与风险捷径

玩家承诺：每圈根据路线与机关时机做决定，精准驾驶用更短路线和出口加速换取领先。

核心循环：先读岔路标识 → 选择宽阔主路或内侧捷径 → 在喷气间隙/移动路障空位穿过 → 出口获得加速 → 回主路继续争夺名次。主路18m宽，花园捷径12m宽，工坊捷径9m宽；主路保持可通行，不强迫玩家进入机关。撞机关会减速、丢金币，有反馈及短暂无敌，不重置位置。

空间计划：北侧 .10–.35 花园捷径在第一个大弯切内线，喷气口偏在行车方向左侧，安全3秒、黄色预警2秒、红色喷发3秒，始终留右侧绕行；南侧 .60–.89 工坊捷径切过大弯，单个路障横向摆动，有地面轨迹提示。出口 .86 位置设加速板，每条捷径每圈最多触发一次。两个路线均与主路切线相接，保留肩部缓冲，清除捷径范围内旧装饰与旧护栏。

实现约束：沿用60Hz自定义街机碰撞，移动路障使用与模型同步的圆形代理与相对运动扫掠；路线按弧长投影到原有有序检查点，只改变玩家计分/表面查询，不替玩家转向。机关使用比赛时钟，暂停/重开可预测。AI默认走安全主路，仍是可被道具攻击的现有对手。地图绘制分支并以玩家真实位置显示，路标/HUD预告，菜单提供规则提示。云端规则与本机最佳使用新版本隔离旧赛道成绩。

验证：路线连续计分/三圈/逆行与跳关拒绝，合法路面无减速救援，碰撞和机关预警、暂停/重开恢复，真实转向输入跑通两条捷径及完整三圈；桌面/手机可视性和控制检查。
