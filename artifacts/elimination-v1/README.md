# 末位淘汰赛完成与验收

首页新增「末位淘汰赛」。第30秒首次淘汰，此后50/70/90/110秒淘汰末位；最后5秒显示警报，末两名在HUD、地面与小地图标记。比赛按有效累计赛程排序，不限圈数；同赛程保留上一排序。暂停和后台停表，剩两人配乐提速。

被淘汰车辆立刻退出驾驶/碰撞/AI/道具目标/排名/地图，清理自己的及追踪它的投射物，短暂升起缩小后退场。玩家出局立即结算，其他仍存活者不虚构最终名次。冠军、存活时间、真实超车次数、本机最佳名次、时间线和重试完成。普通竞速/计时/杯赛的3圈规则保持，淘汰赛记录独立保存在本机，不上传三圈榜或计入每日成长。

## 代码

- src/elimination.ts：纯赛钟规则与稳定排序，输入校验，防重复/回退，快照隔离。
- src/elimination-view.ts / elimination.css：响应式警报和结算，状态读取与游戏规则分离。
- src/main.ts：模式生命周期、活跃车辆过滤、清理/退场、超车迟滞统计、音频与独立存储。
- src/driving.ts：默认lapLimit=3，淘汰赛设为null；原自由驾驶、检查点和扫掠圆碰撞不变。

## 使用

http://localhost:5173/?v=elimination-v1 → 末位淘汰赛 → 开始比赛。原键盘/触屏/手柄映射保留。

本地预览运行时执行npm run test:elimination。没有新增服务器配置，也没有部署至阿里云。实体手机/手柄本轮未验证。规则与UI模块由独立子任务完成；额外独立代码复查因额度未执行，主任务完成集成检查、真实输入与生产测试。
