# 核心循环契约

玩家通过方向/油门/漂移、道具与捷径超越对手，避免在每轮截止时落在末位；存活给出新一轮机会，失败给出明确名次、存活时间、超车次数和立即重试。最后一位存活者获胜。

固定60Hz顺序：输入→驾驶与有效检查点→AI驾驶及车辆碰撞→拾取/道具规划→投射物命中→技巧及真实超车统计→更新淘汰顺序与期限→清理被淘汰车辆→结算或视效。淘汰在本步物理状态之后判定；漏检查点使用受限有效赛程，不按原始投影冒进。

首次30秒、随后每20秒、最后5秒预警。倒计时发车、暂停、后台不消耗比赛时钟。玩家出局立即结束，末局剩1时决出冠军。重试重新生成规则状态、6名车手、道具与计时；普通模式重新恢复3圈结束条件。
