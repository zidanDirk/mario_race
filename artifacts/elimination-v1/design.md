# 末位淘汰赛设计

玩家通过驾驶、漂移、道具攻防和捷径保住非末位；每次淘汰前5秒给出倒计时、末两名和位置标记，存活直到最后一人成为冠军。第一轮第30秒淘汰，此后50/70/90/110秒；开局3.6秒发车倒计时不计入。暂停、失焦和后台停表。

沿蘑菇环线无限圈运行，累计有效检查点赛程决定顺序，逆行或漏检查点不能获得虚假领先。同进度保留上一排序。每次淘汰明确提示并短暂升起缩小退场，即刻退出碰撞、AI、道具目标、地图/排名；其遗留/追踪道具同时清理。玩家被淘汰后立即结算名次、存活时间和真正超过活跃对手的次数，其他未完赛者不虚构名次；可一键重试。

独立菜单模式，角色/难度沿用。单独本机最佳名次，不生成单场云比赛凭证、不上传三圈榜、不改变每日成长和杯赛状态。计时、普通竞速、杯赛返回原三圈规则。复用60Hz自定义驾驶/扫掠圆碰撞，赛道/操控不变。

最后二人对决提升背景音乐速度；淘汰警报简短可静音。HUD复用左上圈数区域，手机130px宽避免计时器。预期截图：桌面警报、淘汰反馈、胜利/失败；390x844警报/失败，844x390警报。浏览器边界场景+真实输入完整淘汰赛验证；使用既有Playwright，无新视觉测试框架。
