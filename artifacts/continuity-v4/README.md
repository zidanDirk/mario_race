# 超车可见性与误救援修复

## 修复内容

1. 取消对手位于玩家身后 3～23 米时强制设置 `visible=false` 的逻辑。比赛中的对手持续存在，由正常相机视野决定是否在画面内；后视也能看到已被超越的车辆。菜单仍只展示所选车手，受击短暂闪烁保持原行为。
2. 将检查点计分与车辆救援分离。漏点不再触发传送，只显示返回检查点提示；检查点有效横向范围扩至 24 米，覆盖路面及附近路肩。顺序检查点仍用于防止跨圈抄近路。
3. 普通草地偏离不再在 1.2 秒后强制复位。自动救援要求车辆距最近赛道超过 60 米并持续 3 秒未返回，提前显示倒计时；明显向赛道驶回时取消倒计时，距离进入 55 米范围时也取消。真正救援后保持检查点数量。

## 已复现的失败

- 浏览器在对手相对位置 +6、+1、-2 米时 visible=true，-4、-8、-15、-22 米时 false，-25 米又恢复 true。
- 三个独立物理复现均失败：13 米路肩通过检查点漏记；车辆已在路面但曾漏点时仍自动传送；30 米草地静止时被强制拉回。

## 验证

- `node --experimental-strip-types tests/continuity.mjs`：6 项通过，覆盖路肩计分、路面漏点不传送、草地不传送、远离赛道先警告再救援、驶回取消倒计时、捷径不能伪造检查点。
- 原有驾驶/碰撞/道具的 27 项单元检查通过。
- `node tests/continuity-browser.mjs`：5 组通过，连续检查 +6 至 -25 米的 32 个位置、后视、路面及草地误救援、真正越界倒计时、手机布局。页面和控制台错误为空。[完整结果](continuity.json)
- `npm run build` 通过，JS 602.51 kB / gzip 164.81 kB；Vite 单包大小提示仍为非阻断提示。
