# AI 道具攻防验收

实现 AI 实际取箱、独立双格库存与四类道具策略；玩家后挂防御、来袭方向提示；标准/休闲难度与分榜成绩。详细行为约定见 design.md。

## 验证结果

- 生产构建通过；现有打包体积提示仍存在。
- 80 项确定性游戏检查通过（驾驶、碰撞、库存、连续性、捷径、幽灵、成长，以及新增 6 项输入/命中顺序、14 项 AI 策略检查）。见 unit.txt。
- 22 组后端检查通过：难度凭证、旧数据库迁移、分榜、幂等成绩与每日成长等。见 server.txt。
- 10 组攻防浏览器检查通过，零脚本异常。涵盖真实吃箱、四道具执行、短按/长按、后方拦截及备用格保护、正面受击、暂停/触摸取消/模拟手柄断开、计时隔离和手机布局。见 browser.json。
- 10 组真实本地 HTTP/SQLite 浏览器联调通过，验证登录、重试去重、标准/计时分榜、休闲保存但不改写标准成绩、手机账户界面及退出。见 cloud/browser.json。
- standard：真实键盘驾驶完成三圈，48.700 秒；AI 取箱 18 次、使用道具 8 次、击中 AI 2 次、击中玩家 0 次。
- casual：真实键盘驾驶完成三圈，50.283 秒；AI 取箱 22 次、使用道具 13 次、击中 AI 4 次、击中玩家 1 次。
- 两档比赛前 30 秒均有 AI 实际取箱和使用道具，比赛脚本无传送/改圈数，零浏览器脚本异常。见 races.json。

- 15 组原有交互回归通过，零浏览器异常：护栏撞击/反弹、问号箱轮盘/重生、库存、红壳弯道追踪、加速、受击、赛车分离及移动端。见 interactions.json。旧测试已改为观察玩家所取箱子和实际图标变化，受击用例移至开场保护期后。

## 查看与复跑

`npm run build`、`npm run test:unit`、`npm run test:server`；本地预览启动后运行 `npm run test:combat`。云端浏览器联调使用 `npm run test:cloud`。

截图：difficulty-menu.png、rear-defense-warning.png、mobile-menu.png、mobile-defense.png、standard-finish.png、casual-finish.png。桌面/移动布局已人工查看；手机检查为 Chrome 模拟视口和指针输入，手柄检查为注入 Gamepad 状态，未做物理手机/手柄测试。

云端验证使用本地测试登录和 SQLite；真实微信/Google 凭据与阿里云部署仍待用户提供。标准榜使用规则版本 3，计时榜保持 2；休闲保存比赛与成长，但不参与标准排名。当前仍是浏览器驱动模拟，未增加服务器权威反作弊。
