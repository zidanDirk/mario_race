# 赛车配置与试驾 — 完成

入口：首页 → 赛车配置。轻巧型、极速型和漂移型全部开放，实际影响速度上限、提速响应、抓地、转向、侧滑和漂移蓄力，不是只更换界面标签。20 秒试驾沿蘑菇赛道使用真实驾驶，暂停停表，完成显示非涡轮峰值与距离，返回恢复原赛制。不会写入比赛、幽灵、技巧或成长成绩，也不会创建云端比赛凭证。

## 实现与记录

- `src/loadouts.ts` 提供三个配置和本机选择保存；`src/driving.ts` 消费真实物理参数，未显式指定时保留原模型默认值。
- `src/loadout-view.ts` / `loadout.css` 提供参数比较、取舍说明、键盘隔离及手机可滚动布局。`src/main.ts` 负责模式转换、试驾统计与比赛期间锁定配置。
- 本机三圈最佳、幽灵、技巧、杯赛和淘汰记录使用配置独立键；旧数据保留。QA 数据使用独立键。
- 云 GP 规则升级至 4、TT 至 3，旧成绩不混入新驾驶模型榜单。数据库迁移至版本 5，保留历史用户、会话、成长和比赛，旧配置标记为 legacy。新凭证绑定配置，结束和重试不能换配置；榜单返回最佳成绩使用的配置，三种配置同榜。

## 复现与范围

启动 `npm run dev` 后运行 `npm run test:loadouts`，后端测试另用 `npm run test:server`。默认使用本机 Chrome，可用 CHROME_PATH 覆盖。生产测试自建临时 SQLite 和 HTTP 服务，结束清理测试数据库。

本轮未部署阿里云、未验证真实微信/Google 凭据，也未测试实体手机或手柄。手机结果来自浏览器视口模拟；既有键盘/触屏/手柄映射保留。配置偏好和幽灵目前只存本机。
