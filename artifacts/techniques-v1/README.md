# 技巧竞速验收

实现：持续跟车尾流、蘑菇赛道两个可绕行低跳台、起跳时机与落地加速、三重蘑菇、超级喇叭，配套 AI 行为、键盘/标准手柄/触屏输入与成绩版本隔离。使用现有程序化模型、音效与 WebGL 管线，无新依赖或付费素材。

## 玩法与边界

- 尾流：同路同向，前车在 4–18 米内、横向距离不超过 2.5 米，连续 1.1 秒触发 1 秒加速，冷却 3 秒；幽灵、空中和无效赛程不参与。
- 跳台：t=.72/.785，右侧 lane=3.5，宽 5 米、长 9 米、高 1.6 米。前后 0.15 秒按跳跃有效，成功落地加速 1.05 秒并获得 120 基础技巧分。真实高度和重力，跳台不修改水平坐标；地面弹体按高度判断命中。
- 三重蘑菇每次按下只消耗一枚，长按不会重复消耗或使用备用槽。喇叭检查 12 米世界距离、高度、遮挡和保护期，清除附近危险物并攻击有效对手。
- AI 共享尾流和跳台规则；不跳台的 AI 提前选择左侧平路。云 GP5 / TT4，本机各类记录升级命名空间，旧数据保留。

## 画面与发布

采用现有 Playwright 场景截图与真实比赛脚本；本次不增加脆弱的整图逐像素断言。已查看 `ramp-approach.png`、`ramp-air.png`、`ramp-landing.png` 连续动作帧以及 `mobile-items.png`、`landscape.png` 和三圈结算截图。浏览器生成的画面可见、动作连续，手机按钮可操作。最终复查将竖屏技巧提示移至计分面板下方，避免遮挡左下计时面板，输入测试同时校验两者不重叠。

构建见 `build.txt`：TypeScript 与 Vite 通过，主 JS 744.81 kB / gzip 217.89 kB，沿用已有大包提示。当前实机手机、实体手柄、真实微信/Google OAuth 及阿里云部署未验证；模拟输入验证不替代实体设备体验。后端凭据需求见 `deploy/README.md`，这次玩法无新增配置要求。

复现：启动 `npm run dev` 后执行 `npm run test:techniques`，Chrome 可用 `CHROME_PATH` 覆盖。该命令顺序运行浏览器测试，避免多个 WebGL 实例竞争 GPU。
