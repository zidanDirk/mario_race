# 比赛背景音乐验收

新增原创两首配乐：晴空冲刺（144 BPM）与月下疾驰（152 BPM），各32小节。合成铜管、切分键盘、跳跃贝斯、鼓组；夜赛独立编曲。最后一圈升全音、提速12.2%；冲线短乐句；音乐会为事件提示音短暂降低音量。

首版浏览器现场合成需要约10–11秒，已改为预渲染MP3，在用户手势后的倒计时期间加载当前赛道。两曲共2.08MB，构建后的主JS约705kB/204kB gzip；原有大包提示仍在。

## 已验证

- TypeScript与生产构建通过；未添加npm依赖。
- `browser.json`：6组浏览器检查通过，真实AudioContext输出RMS约0.033，默认点击开始后播放；静音、暂停续播、手机音量滑块、最后一圈、冲线、双站切换、重赛、退出、设置持久化和后台静音通过；循环源无持续叠加，浏览器异常0。
- `production.json`：3组生产检查通过；普通URL不暴露QA钩子，点击开始至音乐约3746ms（含3.6秒倒计时）；只加载当前曲目。两首MP3解码后小节时长准确、峰值低于0.76、循环边界跳变低于0.007。模拟素材加载失败后仍可驾驶，通过继续比赛手势可重试。
- `render.json`：完整音乐离线渲染的样本均有限，无削波，每250ms窗口均有信号；循环接缝与32小节时长检查通过。
- 服务端22项测试通过，含已有登录/成绩/成长检查；新增MP3静态文件类型为audio/mpeg。见server-tests.txt。
- `mobile-mix.png`：390×844音量面板与按钮可见，无横向溢出。

## 使用

刷新游戏并点击开始比赛即可听到；右上角声音按钮可静音。暂停 → 声音设置，可分别调节音乐和引擎/提示音，记住本机选择。

试听文件：mushroom-preview.wav、castle-preview.wav（各16秒，带结尾淡出）。源编曲和重建方法在src/audio/README.md。

素材是本地合成的原创音乐，无原版录音、第三方采样或外部服务调用。测试使用Chrome实际音频图与波形分析；未进行实体手机音频或主观人工听感评测。
