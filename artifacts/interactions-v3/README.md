# 碰撞与道具交互修复

用户问题：撞护栏无碰撞；撞问号箱缺少反应；自查同类交互。沿用本地重建角色和现有单人赛道，本轮不替换人物资产。

## 根因与修复

- 护栏原来只是场景网格，驾驶模块没有静态障碍碰撞。现在可见护栏与碰撞代理共用端点，护栏沿弯道布置；使用固定 60 Hz 的圆形车体对线段胶囊进行连续扫掠，接触分离始终执行，音效/火花才有冷却。正撞减速回弹，斜擦沿栏滑动，重撞取消加速和漂移。树干、蘑菇茎、起点立柱及路牌柱也接入简化代理。
- 原问号箱只有立即赋值和细小粒子，已有道具时直接忽略接触。现在碰箱产生彩色碎片，箱体消失，道具栏轮播 1.5 秒后开奖；可按道具键加快但不会同次按键误发射。双格库存按顺序使用，备用前移，满格提示且不覆盖已有道具。箱子约 3.5 秒后缩放重生，暂停冻结轮盘，重赛清空所有待开奖状态。
- 车手相撞原先只在冷却结束时推开一点，双方仍可能重叠。现在每帧分离玩家与近邻车手，对双方施加位移和速度影响。
- 红壳原来直接瞄准世界空间目标，急弯会穿草地抄近路；现在沿赛道追踪并在接近目标时靠向其车道。绿壳使用实际障碍反弹，红壳撞障碍碎裂。发射前的 3.3m 出生位移也执行扫掠，避免贴栏隔墙发射。
- 香蕉和龟壳原先主要表现为突然变慢。现在分别触发打滑/旋转颠跳、掉落最多 3 枚金币的反馈、加速取消及短暂无敌，避免同帧连续扣血式命中。
- 蘑菇或较长涡轮经过加速带时，原来会被 1.4 秒加速覆盖而缩短；改为保留较长时长。
- 道具网格的几何和材质改为复用；重赛清理库存、投射物、碎片和受击状态。

本轮继续采用自定义街机碰撞，无刚体引擎。碰撞使用代理而非高精度角色三角网格；平面赛道不包含飞行或高台立体碰撞。
