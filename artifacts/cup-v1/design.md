# 新赛道与双站杯赛

玩家用两场完整比赛争夺总冠军：蘑菇赛道三圈 → 积分中场 → 城堡夜赛三圈 → 总积分颁奖。一站失误可在下一站追回；重复熟悉不同弯道节奏和道具/技巧时机。

首站保留蘑菇赛道及双捷径机关。第二站新建月夜城堡环线，长直道、连续宽 S 弯及有渐变入口的12米窄桥；明亮车身、青色路线边缘与暖色灯火保证可读性。道路、道具点、加速点来自轨道配置，路面判定与护栏共用宽度采样。沿用60Hz世界坐标驾驶、扫掠圆碰撞、AI道具攻防和技巧分，不引入新操控或掉落惩罚。

六名车手每站名次给15/12/10/8/6/4分，六圈总和决定冠军。各站按玩家冲线时的完成顺序和未完赛车辆进度结算，明确说明；不编造AI用时。积分相同按冠军次数、两站名次和、最后一站名次打破平局。角色/难度在杯赛开始确定，两站一致。

中场由用户点「下一站」继续；「重跑本站」撤销本场结果但保留此前站积分。暂停重赛同理；完成整杯后再挑战从第一站开始；返回首页清空在途杯赛。场景最多缓存两份，切站重置车辆、机关、道具、检查点与技巧连击，更新小地图和夜景灯光；单场计时/幽灵不混用城堡轨道。

杯赛总成绩和每站技巧纪录先存本浏览器；杯赛不提交现有蘑菇单场榜，也不伪造云端每日成长，菜单/结果明确标注本机杯赛。现有标准/休闲单场与计时榜仍按原规则工作。新赛道首版通过杯赛第二站体验。

验收：纯积分状态/平局/重赛/重复提交、曲率/闭合/道路宽度/摆放/有序检查点、城堡真实三圈驾驶、完整双站杯赛和回到单场、窄桥碰撞、道具攻防、计时幽灵隔离、桌面/手机/生产构建/两场景缓存稳定性。
