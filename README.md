# Mario Kart · 蘑菇王国大奖赛

本地 Three.js 卡丁车游戏：选择马里奥、路易吉、碧姬、耀西、奇诺比奥或瓦力欧，与五名 AI 对手竞速三圈，或在计时挑战中追逐个人最佳幽灵。角色为本地重建的立体模型，非原版游戏资产；操控参考马里奥赛车的基本规则，物理参数为本项目调校。

## 启动

```sh
npm install
npm run dev
```

打开 http://localhost:5173 。生产版本运行 `npm run build`，然后 `npm run preview`。

## 操作

| 动作 | 键盘 |
|---|---|
| 加速 | W / ↑ |
| 刹车、停车后倒车 | S / ↓ |
| 左右转向 | A、D / ←、→ |
| 起跳、持续漂移 | 加速转向时按住 Space / R |
| 使用道具 | E / Q：短按投出，长按后挂防御，松开投出；也可操作道具栏 |
| 向后看 | 按住 C |
| 暂停、继续 | Esc / P |
| 回到赛道 | Backspace，损失 3 枚金币 |
| 开始 | Enter / 开始比赛按钮 |

- 车辆按自己的朝向自由行驶。入弯起跳并按住漂移键，反打方向可以调整弧线；路面上蓄力，蓝、橙、紫三个阶段，松开漂移键释放涡轮加速。
- 倒数「2」时开始按住油门，可获得火箭起步；过早长按会短暂熄火。加速与刹车同时按住，在低速时可快速原地转向。
- 金币最多 10 枚，每枚提高极速。蘑菇提供 2.2 秒冲刺；绿龟壳直线飞行并反弹，红龟壳追踪前方对手，香蕉留在车后。
- 撞到白色护栏、树干、蘑菇茎和起点立柱会被阻挡并减速，重撞会中断加速；斜擦护栏可以沿栏滑动。
- 问号箱接触时碎裂并显示道具轮盘，1.5 秒后开奖；按道具键可加快轮盘，再次按键使用。最多持有两个道具，使用首格后备用格自动前移。箱子约 3.5 秒后重生；满格再撞箱也会有提示且不会覆盖库存。
- 香蕉命中触发打滑，龟壳命中触发旋转颠跳，并损失最多 3 枚金币和当前加速。短暂无敌防止连续重复受击。红壳沿赛道追踪，绿壳在实际护栏处反弹。
- 草地减速，普通偏离不会强制复位。距离最近赛道超过 60 米且持续 3 秒未返回才会救援，提前显示倒计时；驶回途中会取消。漏过检查点只提示返回，不传送车辆。检查点覆盖赛道及附近路肩，仍需按顺序通过八个检查点才计入完整一圈。
- 对手超车后仍正常显示，按住 C 可查看后方车辆。
- 手机支持屏幕加速、刹车、转向、漂移和后视；短按道具栏投出，长按后挂防御，松开投出。
- 浏览器标准手柄：左摇杆转向，A 加速，B 刹车，右肩键跳跃/漂移，左肩键道具，上方键后视，START 暂停。识别到 Nintendo / Switch 手柄时使用右侧 A / 下方 B，其他手柄使用下方 A / 右侧 B。
- 完赛显示名次和用时；最佳用时存于当前浏览器。声音按钮开启合成引擎与事件音效，默认静音。

## 实现与验证

`src/driving.ts` 实现固定 60 Hz 的世界坐标运动、漂移和检查点；`src/collision.ts` 使用扫掠圆与静态胶囊碰撞避免高速穿栏；`src/items.ts` 管理双道具库存与轮盘；`src/characters.ts` 构造角色；`src/world.ts` 构造赛道与赛车；`src/garage.ts` 提供选择界面与操作指南；`src/main.ts` 集成比赛、输入、相机、道具和 HUD。

单元检查运行 `npm run test:unit`；生产预览开启后，`npm run test:interactions` 检查护栏、箱子、道具和触屏交互。运行 `npm test`，覆盖物理规则及浏览器真实键盘输入完整比赛、道具、暂停/重赛、触屏操作。`npm run test:visual` 输出角色、桌面及手机截图。测试使用 macOS Google Chrome；`CHROME_PATH` 可覆盖行为测试的浏览器路径。检查接口仅在 `?test=1` 启用。

验证记录见 [artifacts/final-evidence.md](artifacts/final-evidence.md)。生产文件在 `dist/`。单人本地游戏，无联网多人模式；手柄未做实体硬件验证，手机为浏览器尺寸和触控仿真验证。

规则参考：[任天堂基本操作](https://support-jp.nintendo.com/app/answers/detail/a_id/34439/) · [Mario Kart 8 官方说明书](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/wii_u_6/mario_kart_8/ElectronicManual_WiiU_MarioKart8_EN.pdf)。

## 双捷径与赛道机关

北侧花园捷径（青绿）和南侧工坊捷径（金色）已开放，分别缩短约31m和35m。花园喷气口绿灯安全、黄灯预警两秒、红灯喷发，右侧可绕行；工坊移动路障需要观察空位。每条捷径出口每圈可获得一次加速。主路仍是宽阔安全路线，无需进入捷径也可完赛。

控制方式不变；小地图显示两条分支，操作指南补充机关规则。新赛道成绩使用规则版本2，与旧版最佳分开保存。验证记录见 [course-v1](artifacts/course-v1/README.md)。

## 计时挑战与个人幽灵

在开始菜单选择「计时挑战」。单人完成三圈，首次有效完赛会建立本机最佳；再次挑战会有半透明蓝色幽灵同场回放，可随时切换显示。每圈四个分段，经过分段线时比较累计用时：负值更快，正值更慢。结算显示全部十二个分段，只有更快的完整录像会替换最佳。

计时模式关闭 AI 交通、随机道具箱与道具操作，保留金币、漂移、起步加速、赛道加速、双捷径和机关。暂停会同时冻结计时与幽灵，重开从零开始。切回「道具竞速」即可恢复六人道具比赛。

登录后，两种模式分别保存成绩、个人统计及前十用户排行榜。幽灵轨迹保存在当前浏览器，暂不跨设备同步；清除站点数据会删除本机幽灵，已提交的服务器成绩仍保留。未登录也能建立个人幽灵。

`src/ghost.ts` 负责录制、校验与插值，`src/trial-view.ts` 负责无碰撞幽灵及分段线。运行 `npm run test:trial` 验证完整首跑、再次追逐、暂停、慢成绩保护和手机布局；运行 `npm run test:cloud` 验证模式隔离与真实本地 API。详见 [time-trial-v1](artifacts/time-trial-v1/README.md)。

## 每日挑战与车手成长

点击顶部「✦ 每日挑战」查看今天的三个任务。六种任务轮换出现：完成比赛、累计三次橙色或紫色漂移释放、单场拾取十枚金币、无救援完赛、累计两次捷径出口加速、完成计时挑战。金币任务统计实际拾取次数，受击丢失不扣任务进度；无救援任务同时检查手动和自动救援。

任务在北京时间每天 00:00 更新，按开赛日期结算，只有完整完赛才累计进度。每项获得 100 XP，每天最多 300 XP，重开不会领奖。100 XP 解锁薄荷车漆，300 XP 解锁紫色尾焰，600 XP 解锁「星光车手」称号；在成长面板装备或恢复默认。配色只影响玩家赛车，尾焰在加速时显示，称号会显示在个人标签及云端榜单，不改变车辆性能。

游客进度与装备存于当前浏览器；登录后切换为账号的服务器数据，支持跨设备读取经验与装备，不自动合并游客进度。成绩保存失败时可重试，经验随成绩一起提交且不会重复发放。外观只有服务器确认保存后才切换。

共享规则位于 `shared/progression.mjs`，成长界面位于 `src/progression.ts`。`npm run test:progression` 包括共享规则、实际键盘完赛、事件计数、装备/手机布局与真实本地 API 联调；`npm run test:server` 覆盖迁移和服务端任务结算。验证说明见 [progression-v1](artifacts/progression-v1/README.md)。


## AI 道具攻防

五名 AI 会实际争抢问号箱，通过独立双格轮盘获得蘑菇、绿壳、红壳和香蕉，并按距离、车道和攻击冷却选择时机，也会攻击其他 AI。其当前道具显示在车顶。

- 龟壳和香蕉：短按 E / Q 投出；长按约 0.22 秒后挂在车尾，可抵挡一次后方攻击，松开投出。龟壳默认向前，配合后视向后投；香蕉向后放置。蘑菇按下立即加速。备用道具不会因前一格被击碎而自动发射。
- 触屏道具栏与手柄左肩键采用相同操作。暂停、失焦、触摸取消或手柄断开会取消后挂，保留未发出的库存。
- 实际攻击靠近时显示类型、方向和应对提示；正面攻击不能被车尾道具挡住。开场宽限、全局攻击间隔及受击保护减少连续受击。
- 开赛前选择「标准」或「休闲」。休闲有更长的攻击间隔和受击喘息时间，可保存比赛和每日成长，不计入标准竞速排名。
- 加入技巧竞速后，标准道具竞速采用规则版本 6，计时挑战采用版本 5。旧成绩保留但不参与新榜；计时模式保持无 AI、无随机道具和个人幽灵规则。

`src/ai-combat.ts` 管理 AI 决策；`src/combat-input.ts` 管理按压手势和命中顺序。`npm run test:combat` 验证攻防、输入取消、移动端和两档真实键盘三圈比赛。验证记录见 [combat-v1](artifacts/combat-v1/README.md)。


## 技巧连击

漂亮操作获得独立技巧分：橙色漂移释放 100 分、紫色漂移释放 180 分、贴身超车 120 分、完整通过捷径 160 分。8 秒内连续完成动作，倍率依次 ×1、×1.5、×2、×2.5、×3，最多三倍。重撞、机关/道具受击、手动或自动救援会结束连击，但已得分保留；暂停不消耗连击时间。

超车检查实际前后位置与物理距离，每圈同一对手只奖励一次；逆行、越野、瞬移或单纯名次变化不算。捷径要求从入口进入并抵达出口奖励点，临近出口才切入不算技巧。普通碰撞、道具、漂移加速与捷径出口加速保持原有规则，技巧分不会提高车速，也不参与用时排行榜。

左侧技巧面板显示总分、连击、倍率和剩余时间；结算显示四类技巧次数、最高连击和评价。完整比赛结束后保存本机技巧纪录，标准道具竞速、休闲道具竞速、计时挑战分别记录；放弃/重赛不会写入未完成成绩。技巧纪录暂不跨设备同步，浏览器无法保存时结算会提示。

核心规则与超车检测在 `src/tricks.ts`，界面在 `src/trick-view.ts`。本地开发预览启动后，`npm run test:tricks` 执行构建、核心规则、专项浏览器、完整三圈与生产界面检查。详见 [技巧连击验收](artifacts/tricks-v1/README.md)。

## 城堡夜赛与双站杯赛

首页选择「双站杯赛」：先完成蘑菇赛道三圈，查看中场积分，再点击「下一站：城堡夜赛」挑战第二站三圈。城堡夜赛约 988 米，有连续弯、长直道、火把城门和渐变窄桥；青色边缘标出路面，两侧护栏参与实际碰撞。继续使用现有驾驶、四类道具攻防及技巧连击。

六名车手每站按名次获得 15 / 12 / 10 / 8 / 6 / 4 分。每站在玩家冲线时结算：已完赛车手按完成时间，其余按赛道进度；积分相同依次比较获胜次数、名次总和、末站名次。完成两站显示领奖台和全部车手积分。

「重跑本站」撤销当前站结果并保留之前站积分；完整杯赛后的「再战双站杯赛」从第一站开始。「退出杯赛」丢弃当前杯赛进度。车手和难度在两站间保持一致。城堡夜赛首版通过杯赛第二站进入。

完整杯赛结果保存在本浏览器，首页可显示同难度的上届名次；每站技巧纪录也单独保存。杯赛暂不计单场云端用时榜或每日成长，避免将不同赛道/赛制成绩混排；现有单场与计时模式保持原有服务。返回首页切换模式即可继续单场或个人幽灵挑战。

配置位于 `src/tracks.ts`，夜赛场景位于 `src/night-world.ts`，积分状态与界面位于 `src/cup.ts` / `src/cup-view.ts`。`npm run test:cup` 包含构建、规则/赛道检查、专项杯赛交互、真实六圈和生产联调；需先启动本地开发预览。详见 [双站杯赛验收](artifacts/cup-v1/README.md)。

## 末位淘汰赛

首页选择「末位淘汰赛」。第30秒首次淘汰末位，之后每20秒淘汰一人；最后5秒警报，最后存活者获胜。不限制圈数，按照有效累计赛程排序；暂停或切换后台时停表。被淘汰后可以查看名次、存活时间、超车次数并立即重试。成绩独立保存在本机，不计三圈云榜和每日成长。

`npm run test:elimination` 运行构建、规则、浏览器、完整实跑与生产隔离检查（需本地预览和Chrome）。详见 `artifacts/elimination-v1/README.md`。

## 赛车配置与试驾

首页点击「赛车配置」选择三种全部开放的配置。轻巧型起步和受撞后提速更快，参考极速约 140 km/h；极速型直线最快，约 158 km/h，但起步较慢、过弯需要提前减速；漂移型转向更稳，蓄力速度为基准的 1.2 倍，参考极速约 143 km/h。参考值按零金币、无加速计算；金币与涡轮仍按原规则生效。

选择立即生效并保存在本浏览器，适用于竞速、计时、杯赛和淘汰赛。比赛期间和杯赛两站之间不能更换。点击「20 秒试驾」使用真实油门、转向、刹车和漂移操作体验配置，结束显示平跑峰值与行驶距离，支持暂停、重试和返回车库；返回时恢复此前选择的赛制。

试驾关闭对手、金币和道具，不保存正式比赛成绩、幽灵或成长进度。正式比赛的本机最佳、幽灵、技巧、杯赛和淘汰记录按配置分别保存，旧记录保留。云端开赛凭证绑定配置，榜单显示最佳成绩所用配置；同一赛制的三种配置共同参加新版榜单，不需要购买或解锁。

运行 `npm run test:loadouts` 检查构建、驾驶模型、车库交互、真实输入三种试驾与三圈计时、生产接口联调；需先启动本地开发预览并安装 Chrome。后端迁移与成绩绑定另由 `npm run test:server` 覆盖。详见 [配置与试驾验收](artifacts/loadouts-v1/README.md)。本功能无需新增服务凭据，尚未部署到阿里云。


## 技巧竞速：尾流、跳台与新道具

连续贴近前车尾部约 1.1 秒可获得一次尾流加速，利用加速变线超越。只计算同一路线、同向行驶的真实车辆，个人幽灵不提供尾流。

蘑菇赛道后段新增两个右侧低跳台，左侧平路可直接绕行。在起跳前后点按原漂移键（键盘 Space / R、手柄右肩键、触屏「跳跃 / 漂移」），成功落地获得短加速和 120 基础技巧分；长按不会自动连续触发。漏按仍可正常起跳落地。

- 三重蘑菇：分三次使用，每按一次消耗一枚，界面显示剩余次数。
- 超级喇叭：立即震开附近对手、清除近处龟壳与香蕉，护栏会遮挡效果；受击或救援保护期间不会被连续攻击。
- AI 同样使用尾流、跳台和新增道具；平路 AI 走左侧避开坡体。

计时挑战可练跳台，保持无 AI 和随机道具。所有成绩与旧规则隔离，历史数据保留；云端当前 GP6 / TT5 与客户端一致。无需新增服务或凭据。

## 漏点恢复

出现「检查点未通过」时，小地图橙圈会标出待补过的位置。可自行返回顺向补点，也可点击「回到检查点前」（键盘 Backspace / 标准手柄 Select、−），回到漏点前约 8 米并朝向赛道正向。继续加速通过后恢复计圈。计时继续，最多扣 3 金币，重复长按不会重复扣费；暂停时不触发，不会自动补算检查点或突然传送。

本地预览运行时可执行 `npm run test:checkpoints`。详见 [漏点恢复验收](artifacts/checkpoint-assist/README.md)。


## 机关战术：看路面、选路线、用道具突破

双站杯赛第二站「城堡夜赛」加入蓝色湿滑内线、干燥外线与双传送带。湿地降低抓地，离开后逐渐恢复；传送带沿道路推动赛车，停车或倒车也会被带动。箭头指示方向，每 12 秒换向，最后 2 秒变黄提醒；中央始终保留普通路面。赛车配置里新增「城堡机关 · 20 秒试驾」，可反复练路面且不记录成绩。

- 炸弹：道具键前抛，按住后视再使用则后放；2.2 秒引信，接触车辆可提前引爆。橙圈标出 12 米范围，临爆变红；护栏阻挡爆炸，超级喇叭可安全清除炸弹。
- 星星：5 秒提速、道具与机关免伤，接触可击退对手；仍需自己转向，护栏仍会碰撞。最后一秒闪烁提醒结束。
- 键盘 E / Q、触屏道具栏、手柄左肩使用同一规则；按住不会重复消耗备用格。AI 也会选路、避炸弹、使用新道具；按名次与领先距离调整抽取权重，强道具有独立冷却。

暂停冻结路面换向、引信和星星；重赛、退出与杯赛切站清理状态。当前云端 GP6 / TT5 与本机新规则记录隔离旧成绩，历史保留。无需新增服务或凭据。

验收：先开启本项目预览，再运行 `GAME_URL=http://localhost:5173 npm run test:tactics`。未设置 `GAME_URL` 时新版浏览器测试使用 5180，以避免与其他项目抢占端口。详细证据见 [tactics-v1](artifacts/tactics-v1/README.md)。
